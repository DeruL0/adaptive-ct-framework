# 预算约束下的自适应多类型体积重建：方法、实验与现状

数据：figure473（体积 473×1024×1024，平行束，探测器 1024×1024）。机器：RTX 5070 Ti 笔记本（12 GB 显存），项目内 `.venv`（Python 3.10，torch 2.11 + CUDA 13.0，可重编原生扩展）。
本文记录到提交 cf3595c 为止的全部内容；每个数字都注明来自哪次运行或测量。第 4.8 节起是 2026-10-08/09 这一轮（前瞻的替代、字节分配、正则的尺度、细节评估）。

## 1 目标与规则

**目标**：从多视角平行束投影重建物体的三维衰减系数场（处处 ≥ 0），存成不超过字节预算的文件（主线 8 MiB = 8,388,608 字节）。
**数据划分**：训练 240 个视角（求解和决策只用这些）；检验 16 个视角（每轮报告投影误差，不参与任何决策）；测试 4 个视角（只在最后评测）。
**固定规则**：
- 只用投影：不用滤波反投影等传统重建结果做初值；真值体只在训练结束后用于评测和离线诊断，不用来选步长、停止时机、轮数或子集数。
- 替换方法时彻底删除旧代码、兼容接口和旧配置键；只测最新方法；每次运行注明提交号。
- 主线配置键全部必填，缺键报错，不留静默默认值；新功能默认启用。
- 每次实验保存模型并输出切面图。
- git 只在本地完整跟踪，不推送（远端是公开仓库）。

## 2 方法

### 2.1 表示
- **八叉树**：物体所在立方体先分成 48×48×48 个格子，任一格子可再一分为八，最多到第 4 层（相当于 768³）。不再切分的格子叫叶子，叶内坐标 u 每个方向取 0 到 1。
- **三种叶子**（同一棵树可混合）：
  - 常数叶：1 个值；
  - 三线性叶：8 个角值，叶内任一点是 8 个角值按位置的加权平均；
  - 阶跃叶：2 个值 c₀、c₁ 加几何（方向 n、位置 d、宽度 w），叶内值 = (1 − H)·c₀ + H·c₁，H = sigmoid((n·(u − ½) − d)/w) 是沿 n 方向、在 d 处、宽度为 w 的光滑阶跃（w = 0 为硬阶跃）。
  三种叶子的值都是存储值的非负加权平均，所以存储值 ≥ 0 就保证场处处 ≥ 0。
- **切分**保持函数不变：常数子叶照抄父值；三线性子叶取父函数在子叶角上的值；阶跃子叶 n 不变，d′ = 2d − n·(o − ½)，w′ = 2w（o 为子叶在父叶中的位置）。
  例外（有损）：某个子叶里阶跃较小一侧不到其体积 2% 时，这个子叶改为常数叶（取平均值）；否则小的一侧对应的值几乎不影响任何射线，求解时会失去约束、数值发散。用幽灵惩罚替代这条规则的尝试失败了（4.11）。
- **投影**：每个探测器像素对应一条直线，预测值是衰减系数沿直线的精确积分，按叶子边界分段（一条射线在一个叶子里一段），CUDA 计算。三线性叶沿线段是三次多项式，两点高斯求积精确；阶跃叶沿线段 s = n·(u − ½) − d 是线性的，∫H = L·(softplus(s₁/w) − softplus(s₀/w))/((s₁ − s₀)/w) 有闭式解。
  几何固定时场对存储值是线性的：预测投影 = A·c，c 是全部存储值排成的向量，A 的元素都 ≥ 0。

### 2.2 存储格式（预算按它计，codec/）
按层顺序排列（先根网格按光栅顺序，再逐层列出每个分叉结点的 8 个子格），不存任何指针和坐标，解码时由顺序还原：
每个根格子 1 位（叶子或继续切分）、每个分叉结点一个 8 位掩码（哪些子格继续切分）、每个叶子 2 位类型、值用半精度（fp16）。阶跃叶的几何打包成 32 位：方向用八面体编码（把单位球面摊平到正方形上）2×10 位，d 8 位，w 按对数刻度 4 位（0 表示硬阶跃）。
**每叶字节**：常数 2.25，三线性 16.25，阶跃 8.25；每次切分多 1 字节加 7 个子叶；头 64 字节。旧格式是 5 / 19 / 15 字节加每次切分 64 字节，所以同样 8 MiB 现在能装约两倍的内容。
导出时存储值和几何四舍五入到存储精度，再重新加载评测（若有值超出半精度范围直接报错）。

### 2.3 计算格式（GPU，representation/octree.py）
叶子按类型排成“三线性 | 阶跃 | 常数”，同类型内按 Z 序曲线（三个坐标的二进制位交错）排列，空间上相邻的叶子在内存里也相邻。叶子的类型和值的位置都由序号直接算出（三线性叶 i 的 8 个值在 8i 处，32 字节对齐，两次 128 位读取）；阶跃几何只给阶跃叶存，每叶一条 32 字节记录；树 = 根网格一个 32 位数组 + 每个分叉结点一行 8 个 32 位子项（非负为叶子序号，负数为分叉结点序号）；值直接是物理衰减系数。每叶的缓冲区约 30 字节（旧布局 141 字节）。

### 2.4 解码（只用于渲染和评测）
解码 = 按叶子函数在体素中心取值。可选的**去块滤波**（evaluation/deblock.py，e5937f6）仿视频编码 H.264/HEVC 的弱滤波：沿三个轴依次检查相邻体素 p₀ | q₀，若它们属于两个不同叶子、两个都不是阶跃叶、且跳变小于 δ·h（h 为两叶平均边长，δ 为保边正则的梯度阈值），则 D = (9(q₀ − p₀) − 3(q₁ − p₁))/16（限制在跳变的一半以内），p₀ += D、q₀ −= D。大跳变（真实边缘）和阶跃平面所在的面不动。训练和存储字节都不变；训练结束时导出 `center_slice_deblocked.png`，评测脚本可以用 `--deblock` 给出滤波后的指标。

## 3 流水线

```
48³ 根网格（三线性叶），所有值 = 训练投影平均值的一半
重复（每一轮）：
  0. 阶跃几何更新（数据 + 正则的梯度）            training/geometry.py, regularizer.py
  1. 求解值（树、类型、几何固定；松弛 OS-LALM）   training/solve.py, regularizer.py
  2. 决策：候选阶跃几何（重建梯度 + 邻叶平面）、
     每个叶子 5 个选项的留出收益、面跳变误差       refinement/decision.py
  3. 字节分配：收益 / 延续切分 / 误差切分三份      refinement/decision.py, controller.py
  4. 执行（换类型、切分）
直到：剩余预算不到 1% / 没有动作 / 达到最大轮数 → 最后一轮全分辨率严格求解
导出：舍入到存储精度 → 评测 → 写存储文件 → 中心切面（原样、去块）
```

### 3.0 阶跃几何更新
值固定为上一轮的解，对每个阶跃叶做一步阻尼高斯-牛顿。数据项：按射线累加几何（方向、位置、宽度）的导数 D = (c₁ − c₀)·∂I/∂几何，得到梯度 Σ 残差·D 和 5×5 矩阵 Σ D·Dᵀ（经过多个阶跃叶的射线，叶间耦合忽略）。
**正则项（2cd7cd7 起）**：在保边正则的每个面采样点上，阶跃一侧的 ∂f/∂θ = (c₁ − c₀)·H′·((u − ½)/w, −1/w, −s/w²)，梯度加 β·面积·φ′(t/h)·∂f/∂θ，矩阵加 β·(面积/h)·α·∂f/∂θ ∂f/∂θᵀ，α = min(1, δ/|t/h|) 是在当前点与 Huber 相切、处处不低于它的二次函数的系数（与决策统计里的上界相同，保证半正定）；对面的叶子视为固定（Jacobi 式）。之前正则只在“接受与否”时参与，相邻平面之间没有相互拉近的力（4.12）。
解 (G + 0.1·diag G)·δ = −g，每部分限幅；方向归一化（d、w 同比缩放，函数不变），w ≥ 四分之一探测器像素，平面留在叶内，两侧都 ≥ 2% 体积，否则该叶不动。整步使完整目标（投影误差 + β·R）下降才接受，否则步长减半，最多 3 次；下一轮从上次接受的步长开始试。

### 3.1 求解值
求 min over c ≥ 0 的 J(c) = ½‖A·c − y‖² + β·R(c)。
- **保边正则 R（d10f82e 起，按尺度归一）**：R = Σ_面 ∫ h·φ_δ([f]/h) dS，[f] 是共享面两侧函数之差，h 是两叶中心沿面法向的距离（两叶边长的平均，即有限体积法的两点梯度），φ_δ 是 Huber（|x| ≤ δ 时 x²/2，否则 δ(|x| − δ/2)）。跳变按“分摊在两叶之间的梯度”计价：小跳变代价 面积·t²/(2h)（对称内罚间断有限元的 1/h 权重），大跳变约 面积·δ·|t|（全变差，与 h 无关）。δ 是梯度阈值（单位：值/盒单位），β 是总强度；它们的分工见 4.13。每个共享面从较细一侧的面上取 2×2 个两点 Gauss-Legendre 点（0.5 ± 1/(2√3)，各占四分之一面积，对常数/三线性叶的跳变平方积分精确）。主线 δ = 1.5、β = 9。
- **求解器（2765667 起）**：松弛 OS-LALM（Nien & Fessler 2016）：视角按角度交错分成 12 个子集，D_L = diag(Aᵀ·A·1)，D_R = β·正则曲率上界，α = 1.999，ρ 按子迭代递减；正则的基权重在一次求解内冻结（58ef7e4）。一轮的求解在最后一个周期目标相对下降 ≤ 5e-3 时收敛（至少 3 个周期，每次调用最多 12 个周期，未收敛就续解）；最后一轮 ≤ 1e-3、最多 40 个周期。最细叶子在探测器上还跨 ≥ 2.5 个合并像素时，用 2×2 或 4×4 合并像素求解。
- **时间上限** `training.max_seconds`：到时保存模型，状态记为 `time_limit_not_converged`。

### 3.2 决策
- **选项**：保持 / 换成常数 / 换成三线性 / 换成阶跃 / 切分成 8 个同类子叶。
- **阶跃的候选几何（48c8df8 起）**：n = 归一化的叶内（含四分之一叶宽邻域）灰度梯度二阶矩 + 相邻阶跃叶法向的外积（按共享面积加权）的主方向；d = 梯度加权中心与相邻阶跃平面换算到本叶坐标后的偏移的平均（只取与 n 夹角 < 30° 且穿过本叶的平面；本叶灰度平坦时只用邻叶）；w = 半个探测器像素。邻叶平面相当于 Dual Contouring 在八叉树单元上用的平面数据，这里只用它定本叶的平面，不生成网格。较小一侧不到叶子体积 2% 的候选不允许。
- **射线**：全部 240 个训练视角的全部像素，按角度相邻的视角交替分成两半。
- **局部重新拟合**：其余叶子固定，对每个选项做最小二乘，满足与求解相同的约束（换类型的值 ≥ 0；切分时每个子叶的常数修正 ≥ −该子叶当前最小值）。一半视角拟合、另一半计算误差，再反过来相加。目标值同求解：每一半 Σ(预测 − 数据)² + β·R，R 在叶子附近换成每个面采样点权重为 面积·min(1/h, δ/|t₀|) 的二次上界，切分时子叶之间新出现的内部面（权重 面积/h，h 为子叶边长）也计入。
- **收益定义**：换类型 = J(自己类型重拟合) − J(新类型重拟合)；切分 = J(当前函数) − J(当前函数 + 子叶常数修正)（依据 4.3）；小于统计精度的收益记为 0。
- **统计量**：CUDA 遍历累加每个（叶子，射线段）102 个数，每个视角 float32、视角之间 double。双精度统计每叶约 2 KB，16 MiB 时 400 多万叶子放不下，所以把叶子分成大小相等的组，每组各走一遍射线；最大组按（空闲显存 − 3 GiB）÷ 每叶 2040 字节估计值的一半取。分配器碎片让保留显存每叶约涨 2.3 KB，按全部估计值分组会占满显存：4.3M 叶子时 3.6M + 0.7M 两组 712 秒，2 × 2.2M 两组 38 秒。
- **降级（a94106c 起）**：三线性叶和阶跃叶只有在“平坦”时才允许换成常数：叶内值的变化范围（三线性 8 个角值的最大减最小，阶跃 |c₁ − c₀|）小于 δ_旧 = 0.02（4.10）。上一轮刚换过类型的叶子这一轮只能保持或切分；子叶在探测器上必须至少跨 1 个像素。
- **面跳变能量**（ad7953b）e_L = Σ 叶子 L 各面采样点上的 面积·h·φ_δ(t/h)（每个点同时记到两侧叶子），即残差型后验误差估计里的面跳变项，在决策开始时按已求解的状态算出。

### 3.3 字节分配与执行
每轮可用字节 = action_share（0.35）× 剩余预算；剩余预算不到 10% 时一次用完（spend_all_below，8078909）。分三份：
- **收益（1 − 0.4 − 0.4 = 0.2）**：每个叶子取“收益 − λ × 多用的字节”最大且为正的选项，λ ≥ 0 取使净增字节不超过这一份的最小值（省字节的选项在损失小于 λ × 省下字节时也会被采用）。
- **延续切分（continuation_share 0.4，984b405）**：父叶是“按收益切分”（在价格下付得起）的叶子，若自己的切分收益为正但没付得起，按“收益 / 字节”从大到小切，直到用完这一份；延续切出的叶子，其子叶不再有资格（只往下多走一层）。
- **误差切分（error_share 0.4）**：其余叶子中单层切分收益为正的，按修正误差 ẽ = 1/(1/e + 1/ẽ_父)（Binev & DeVore 2004，ẽ_父 为父叶被切时的值，最粗层 ẽ = e）从大到小切，e = 面跳变能量 e_L（ad7953b）。切一层误差不降的地方（真实边缘恰好在叶面上）优先级每层减半；收益为正的要求排除“真值本来就在叶面上跳变”的情况。
- **执行**：换类型时，用新类型中与当前函数最接近的函数初始化（叶内 4³ 点最小二乘，值 ≥ 0）；切分保持函数不变。控制器保存每个被切叶子的 ẽ 和“按收益切分”的叶子，供下一轮使用。

## 4 设计决定及其实验依据
以下都是 8 MiB 下的体积 PSNR（对真值，越高越好），除非另注。4.8 起的“体积”由 `scripts/audit/gate_chain.py <运行> main_eval` 给出，细节类指标由 `scripts/audit/detail_eval.py` 给出（定义见 5.5）。

### 4.1 决策视角数（旧存储格式，提交 73f4954 → f474847）
决策用多少个视角，决定能不能看到切分收益：在 73f4954 的最终模型上，第 0 层边缘叶切分收益 > 0 的比例，16 个视角 17%，64 个 50%，240 个 97%。体积 PSNR 35.06 → 36.31 dB。所以决策用全部 240 个。

### 4.2 保边正则（旧形式，按值计价）
在 f474847 的树上从同一起点严格求解，β = 0 / 23 / 231 / 2311 / 7704 时检验视角投影 PSNR 51.124 / 51.124 / 51.151 / **51.280** / 50.908，体积 36.312 / 36.312 / 36.324 / 36.413 / 36.302；按检验视角选 β = 2311（配置里取 2300）。完整流程 aee48e1：36.41 dB。决策也计入正则（e9f0f68）在 24 MiB 下没有额外收益（36.93 对 36.98 dB，在噪声内）。之后在松弛 OS-LALM 下改为 β = 1150、action_share 0.35（1793315）；d10f82e 换成按尺度归一的形式（4.13）。

### 4.3 收益定义的对照（同一份代码，只换定义，8 MiB）
| 收益定义 | 体积 PSNR | 第 3 层叶子 |
|---|---|---|
| 旧：当前残差 − 选项 | 37.33 dB | 6.1 万 |
| 所有选项都扣旧类型重拟合 | 35.57 dB | 6.4 万 |
| **类型替换扣基线，切分按当前残差（现行）** | **37.38 dB** | 21.7 万 |

按计划所有选项都扣基线时质量掉 1.8 dB：切分选项的函数族（当前函数 + 修正）不含父叶的重新拟合，却拿去和重拟合后的旧类型比，不公平，深层切分被压掉。严格的做法是父叶值和子叶修正联合拟合（需要父叶基函数与子叶长度的交叉项），未做。统计量改双精度对结果没有影响（旧定义下 37.334 对 37.333 dB）。

### 4.4 阶跃几何更新（容量测试和接入）
在 24 MiB 的树上用真值拟合（只作诊断）：保持几何只重拟合两个值，体积 36.93 → 37.01 dB，阶跃叶上的误差 −4.9%；方向、位置、宽度一起优化，37.40 dB，阶跃叶误差 −19.9%，表面带均方误差 −11%。这是上限（含对真值噪声的拟合）。接入后（只用投影，每轮一步，提交 32aba67，8 MiB）：37.16 → 37.33 dB，测试视角投影 51.81 → 52.70 dB，切面上左上的细裂缝出现，每轮都被接受（前几轮整步，之后半步或四分之一步）。
**薄片叶**（两平行平面之间一个值，两侧另一个值，17 字节）：在 A 之上再测，体积只多 0.06 dB、多用 1.5 MB，主要在拟合真值里的噪声（平坦区出现细针状笔画），放弃。细缝消失的原因不是缺一种叶子类型，而是需要切到第 3、4 层，这是字节分配问题（4.8、4.9）。

### 4.5 掠射角遍历错误（提交 32aba67 修复）
射线和坐标轴夹角很小时（如 0.47°），沿射线轻推 1e-5 的探测点在 float32 下移动不了慢方向的坐标，跨过格子边界后线段被算进前一个格子，单条射线积分最多错 0.49；训练也受影响，测试视角投影 PSNR 因此一直比检验视角低约 2.4 dB。改成沿刚穿过的面推探测点后，全部 260 个视角上 CUDA 与参考实现最大差 1.8e-6，并有回归测试（去掉修复后 5 个 CUDA 测试全部失败）。修复前的所有结果（含 0aa4c1b）都带这个错误。

### 4.6 “扫描圆外”不能置零
旋转轴是模型第 2 轴，真正的扫描圆在第 0、1 轴平面内，圆外有物体（真值均值 0.035）。之前统计的“圆外占 13–24% 字节”其实是第 1、2 轴半径 > 1 的 DICOM 视野外（真值为零），那是参考体的性质，只用投影时不能当约束。

### 4.7 内核优化中放弃的项（都有实测）
每视角新建梯度数组（0.03 毫秒）；解析计算 A·1（每次求解只省一遍）；反投影按类型选择累加方式（慢 40%）、单线程组直接累加（慢 10%）、线程块 64 或 256（更慢）。

### 4.8 两层前瞻及其替代（a627e3e → 2f0d97b）
**问题**：细缝比子叶还细时，切一层的收益小于字节价格，切两层才看得到（决策树里的 XOR 型近视）。
**两层前瞻**（a627e3e、d7be446）：对 65,536 个“单层切分后剩余残差最多”的叶子复制整棵树并切开，再遍历全部射线评估约 52 万个虚拟子叶的切分收益（子叶各自评估、收益相加，不是两层联合最优）。显存修复后每次决策约 30 秒，检验视角每轮约 +0.2 dB，体积未测，两次运行都停掉。
**替代思路的依据**：文献里前瞻代价高且常无益（Murthy & Salzberg 1995），主流做法是先长后剪（CART、wedgelet/platelet 的动态规划剪枝）或按误差而非一步收益生长；后者在树逼近里有“线性计算量、误差在最优树的常数倍内”的保证（Binev & DeVore 2004 的修正误差）。我们是算子耦合的反问题，长满再剪等于先做稠密重建再压缩，与只用投影、自适应生长的目标相违，所以取“按误差生长”。

### 4.10 平坦降级与阶跃叶普查（a94106c）
**普查**（contnorm04 的 68 万个阶跃叶，按真值分类，只作诊断）：纯空气里 11.2 万个（真值处处 < 0.1），两侧跳变中位数 0.0027，80% 小于 0.02；纯材料内 12.7 万个（中位数 0.029，37% 的平面平行于射线平面）。原因：禁止降级成常数后，三线性叶想省字节只能变成 8.25 字节的阶跃叶，几乎平坦的叶子都成了阶跃叶。
**离线**（不重新求解，阶跃叶换成最小二乘常数）：跳变 < 0.005 的 18 万个，体积 −0.006 dB，省 1.08 MB；< 0.01 的 26.5 万个，−0.014 dB，1.59 MB；< 0.02 的 37.9 万个，−0.029 dB，2.27 MB。
**放开后（e2f2343 + 降级门槛 0.02，flat04）**：37.572 dB（对照 37.584），测试投影 53.37（53.31），381 秒（415）；树变成 176 万叶子（常数 125 万、阶跃 37.7 万），省下的字节都去了第 2 层，体积持平。保留，因为不伤体积、投影略好、更快。fabed08 的失败（47 万次由投影收益驱动的降级，体积 −0.6 dB）与此不同：这里只放行平坦的叶子。

### 4.12 几何步计入正则梯度（2cd7cd7）
geopen04（对照 flat04）：体积 37.553（37.572），测试投影 53.30（53.37）；两阶跃叶共享面上的台阶平均 0.0055 → 0.0045，> 0.02 的面积比例 5.1% → 3.0%，90 分位 0.019 → 0.015；其他面不变；每次运行多约 60 秒（几何统计在 PyTorch 里分块现算基权重）。相邻平面对齐的作用达到，体积持平。

### 4.17 试过但没有做的
- **薄缝探针**（在决策里加一个“薄层”基函数，用投影残差的相关性直接估计两层收益）：每叶多 10 列统计；前瞻的主要成本是复制树后整遍遍历，探针只在完全删掉前瞻时才省时间。被“按误差生长”取代。

此后求解换成松弛 OS-LALM（最后求解快约 7 倍，见 7），决策统计在共享内存里分 35 列暂存（be794df）。现行 8 MiB 全程 7.0 分钟、16 MiB 10.3 分钟（5.2），各部分未重新拆分。

### 6.3 已做的加速
- 8 MiB 全程 18.4 → 11.9 分钟（32aba67 → 2b4dbe9），结果不变：决策和几何统计的同叶线程分列求和、射线按列排列、几何更新从上次步长开始、分组阶段正则梯度每遍一次。
- 反投影同样分列求和（db99906）：每视角完整梯度遍 15.1 → 10.1 毫秒。
- 正则基权重在一次求解内冻结（58ef7e4），省掉每次值与梯度计算里 78% 的基权重重算。
- 决策统计只给需要的叶子开列、正则统计写进统计数组、按空闲显存分组（eac18f4、e2f2343、cf3595c）。
- 几何步的正则统计（2cd7cd7）每轮多约 6 秒，可复用冻结的基权重提速，未做。

## 7 求解器对比（固定树；松弛 OS-LALM 已于 2765667 接入主线）
从 `states/pre_final_solve.pt` 出发，同一个目标 J、同一个投影器、正则和非负约束，统一用固定分母的参考残差 ρ_ref(c) = |c − max(0, c − ∇J(c)/D_ref)| / |c|（D_ref 为起点处的 D_L + D_R）在返回的值上判断；耗时只计算法本身。对比的是松弛 OS-LALM（Nien & Fessler 2016，arXiv:1512.04564 算法 1）：D_L = diag(Aᵀ·A·1)，D_R = β·正则曲率上界，α = 1.999，ρ 按子迭代递减。

| 方法 | 到 ρ_ref ≤ 1e-4 | 目标值 |
|---|---|---|
| 旧求解器 | 62 遍，182 秒 | 241.516 |
| **12 个子集，论文设置（ρ 按子迭代递减，正则梯度每子迭代重算）** | **6 轮，26.9 秒** | 6 轮 236.99，30 轮 235.98 |
| 12 个子集，正则梯度每轮只算一次 | 发散 | 7169 |
| 24 个子集，论文设置 | 第 4–20 轮目标值冲到 8.9 万（纹波），未达到 | 242.56（30 轮） |
| 24 个子集，ρ 按轮次递减、正则梯度每轮一次（第一版实现） | 发散 | 14.7 万 |

体积评测（同一状态、同一棵树）：旧求解器 37.380 dB；松弛 OS-LALM 第 6 轮（26 秒）37.428 dB，之后几乎不变。

## 8 已知缺口与下一步
**已知缺口**
1. **视觉指标**：现有指标没有抓住材料内的零星亮斑和边界折线（5.5 局限）；调参仍需看放大切面。
2. **边界折线和拐角**：每个叶子一张平面，弯曲边界只能拼成折线，拐角需要切到更深。带曲率的阶跃叶（曲面块 surflet）能直接改善，但要改 CUDA 内核的阶跃积分（曲面与射线没有闭式积分）、几何步和编码。
3. **常数叶占多数**（8 MiB 204 万 / 241 万）：叶子之间的台阶靠保边正则和去块滤波处理；去块滤波只在解码时起作用，训练拟合的是未滤波的模型。
4. 切分收益不含父叶值的重新拟合；联合拟合需要交叉项，未做。
5. 阶跃切分的 2% 规则仍是有损的阈值规则（幽灵惩罚替代失败，4.11）。
6. 保边正则的 β、δ 只在 8 MiB 上扫过；16 MiB 下的最优值未测。
7. 各部分耗时在现行代码下没有重新拆分；几何步的正则统计未提速。
8. 训练结束后的部署评测和导出阶段显存峰值 13.2 GB（16 MiB），超过 12 GB，未查明哪一步。

**下一步（建议顺序）**
1. 更贴近视觉的指标：材料内孤立亮斑（相对局部中位数的离群体素）、边缘附近的 Chamfer 距离、边缘扩展函数的半高宽。
2. 16 MiB 下复核份额和 β、δ。
3. 带曲率的阶跃叶（先做真值容量测试，确认边界折线的误差份额，再决定改内核）。
