# 代码框架

从多视角平行束投影重建物体的三维衰减系数场，存成不超过 8 MiB 的文件。只用投影数据：
不用传统重建结果做初值，GT 体只在训练结束后用于评测。

## 表示
- **八叉树**：物体所在立方体先均匀分成 48×48×48 个格子，任一格子可再一分为八（每条边对半切），
  最多到第 4 层（相当于 768³）。不再切分的格子叫叶子。
- **三种叶子**（同一棵树可以混合）：
  - 常数叶：1 个值；
  - 三线性叶：8 个角值，叶内任一点 = 8 个角值按位置的加权平均；
  - 阶跃叶：2 个值 c₀、c₁ 和几何（方向 n、位置 d、宽度 w），叶内值 = (1 − H)·c₀ + H·c₁，
    H = sigmoid((n·(u − ½) − d)/w) 是沿 n 方向、在 d 处、宽度为 w 的光滑阶跃（w = 0 为硬阶跃），
    u 是叶内坐标。
  三种叶子的值都是存储值的非负加权平均，所以只要存储值 ≥ 0，整个场处处 ≥ 0。
  切分保持函数不变（阶跃叶的子叶：n 不变，d′ = 2d − n·(o − ½)，w′ = 2w，o 为子叶位置）。
- **存储**：直接存每个叶子的物理值（半精度；阶跃叶另存方向的两个角度、d、w）+ 每叶 3 字节类型标记
  + 每次切分 64 字节树结构；常数叶 5 字节，三线性叶 19 字节，阶跃叶 15 字节。预算按实际存储的字节计。
- **投影**：每个探测器像素对应一条直线，预测值是衰减系数沿直线的精确积分（按叶子边界分段计算）。
  阶跃叶沿线段的积分有闭式解（s = n·(u − ½) − d 沿线段是线性的，∫H = L·(softplus(s₁/w) − softplus(s₀/w))/((s₁ − s₀)/w)）。
  几何固定时场对存储值是线性的，所以预测投影 = A·c，c 是全部存储值排成的向量，A 的元素都 ≥ 0。

## 流水线
```
48³ 根网格（三线性叶），所有值 = 训练投影平均值的一半
重复（每一轮）：
  1. 求解：树固定，求  min_{c≥0} ½‖A·c − y‖²                        (training/solve.py)
       误差 r = A·c − y；梯度 g = Aᵀ·r（把误差反投影回每个系数）
       每个系数的步长分母 d = Aᵀ·A·1（保证每步不会让目标变大）
       更新 c ← max(0, c − g/d)（小于 0 的置 0，即满足非负约束）
       加速：先把 240 个视角按角度交错分成 24 组、每组更新一次；之后用全部数据更新，
             并在"上一步移动的方向"上额外外推一段（外推点截断到 ≥ 0），方向变差就取消外推
       停止：最优性残差（在可行点上做一次上述更新，系数的相对变化）≤ 容差（每轮 1e-3，最后一轮 1e-4）；
             到遍数上限仍未达到则记为"未收敛"
       粗树用粗数据：最细叶子在探测器上还跨好几个像素时，把 2×2 或 4×4 个像素取平均当一条射线求解
             （射线数少 4 或 16 倍）；最后一轮总是用全分辨率
  2. 决策（每个叶子比较：保持 / 换成常数 / 换成三线性 / 换成阶跃 / 切分成 8 个同类子叶）(refinement/decision.py)
       阶跃的候选几何取自当前重建：n = 叶内（含四分之一叶宽的邻域）灰度梯度二阶矩的主方向，
             d = 沿 n 按梯度大小加权的中心，w = 半个探测器像素
       射线：16 个按角度均匀分布的训练视角的全部像素，相邻视角交替分成两半；
       其余叶子固定（相同背景），对每个选项做局部最小二乘重新拟合（值 ≥ 0）：一半拟合、另一半算目标值，
       再反过来，两次相加 → 收益 = 目标值(保持) − 目标值(选项)（多出来的参数只有在没参与拟合的视角上也更准时才有收益）
       统计量在 CUDA 遍历中直接累加到每个叶子（同一线程束内先合并再原子累加）
       上一轮刚换过类型的叶子这一轮只能保持或切分
  3. 选择：每个叶子取 "收益 − λ × 多用的字节" 最大的选项；λ ≥ 0 取使这一轮的净增字节不超过
       剩余预算 70% 的最小值（省字节的选项在损失小于 λ × 省下字节时也会被采用，省下的字节用于这一轮的增加）；
       选中的全部执行（预算按轮次几何式填满）
  4. 执行：换类型用重新拟合的值初始化；切分保持函数不变；下一轮求解从这里继续
直到：没有净收益为正的选项 / 剩余预算不到 1% / 达到最大轮数 → 最后一轮严格求解
导出：存储值和阶跃几何四舍五入到半精度（不再重新拟合），评测，写入紧凑文件
```

依赖只自上而下：core ← data ← representation ← evaluation ← codec ← refinement ← training；viewer 只读复用下层。

## 视角划分
- 训练 240 个视角：求解和打分只用这些。
- 检验 16 个视角：每轮报告投影误差，不参与任何决策。
- 测试 4 个视角：只在最后评测。

## 运行
```powershell
.venv\Scripts\python.exe -m adaptive_ct.training --config configs\stage7\p1.yaml
scripts\test.ps1
```
环境：项目内 `.venv`（Python 3.10，torch 2.11.0+cu130，匹配本机 CUDA 13.0，可重编原生扩展）。

## 已知缺口
- 阶跃几何只在决策时由当前重建估计一次，求解时不优化方向 / 位置 / 宽度。
- 切分的收益按"父函数 + 每个子叶一个常数修正"估计，对三线性父叶偏保守。
- 保边正则（在检验视角上选强度，候选包含 0）尚未实现。
- 一遍全数据（2.5 亿条射线，正投影 + 反投影）约 12 秒（反投影内核改为线程束内先合并再原子累加，
  原为 35 秒）；其中反投影约占 2/3、正投影约 1/3。

只保留当前方法：旧的训练方式、旧的压缩编码、采样积分、高阶多项式叶等都已从代码中删除，
历史版本只在 git 记录里（标签 `legacy-adam-pipeline` 和此前的提交）。
