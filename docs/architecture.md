# 预算约束下的自适应多类型体积重建：方法、实验与现状

数据：figure473（体积 473×1024×1024，平行束，探测器 1024×1024）。机器：RTX 5070 Ti 笔记本（12 GB 显存），项目内 `.venv`（Python 3.10，torch 2.11 + CUDA 13.0，可重编原生扩展）。
本文记录到提交 5754782 为止的全部内容；每个数字都注明来自哪次运行或测量。

## 1 目标与规则

**目标**：从多视角平行束投影重建物体的三维衰减系数场（处处 ≥ 0），存成不超过字节预算的文件（主线 8 MiB = 8,388,608 字节）。
**数据划分**：训练 240 个视角（求解和决策只用这些）；检验 16 个视角（每轮报告投影误差，不参与任何决策）；测试 4 个视角（只在最后评测）。
**固定规则**：
- 只用投影：不用滤波反投影等传统重建结果做初值；真值体只在训练结束后用于评测和离线诊断，不用来选步长、停止时机、轮数或子集数。
- 替换方法时彻底删除旧代码、兼容接口和旧配置键；只测最新方法；每次运行注明提交号。
- 主线配置键全部必填，缺键报错，不留静默默认值；新功能默认启用。
- 每次实验保存模型并输出切面图。
- git 只在本地完整跟踪，不推送（远端是公开仓库）。

## 2 方法

### 2.1 表示
- **八叉树**：物体所在立方体先分成 48×48×48 个格子，任一格子可再一分为八，最多到第 4 层（相当于 768³）。不再切分的格子叫叶子，叶内坐标 u 每个方向取 0 到 1。
- **三种叶子**（同一棵树可混合）：
  - 常数叶：1 个值；
  - 三线性叶：8 个角值，叶内任一点是 8 个角值按位置的加权平均；
  - 阶跃叶：2 个值 c₀、c₁ 加几何（方向 n、位置 d、宽度 w），叶内值 = (1 − H)·c₀ + H·c₁，H = sigmoid((n·(u − ½) − d)/w) 是沿 n 方向、在 d 处、宽度为 w 的光滑阶跃（w = 0 为硬阶跃）。
  三种叶子的值都是存储值的非负加权平均，所以存储值 ≥ 0 就保证场处处 ≥ 0。
- **切分**保持函数不变：常数子叶照抄父值；三线性子叶取父函数在子叶角上的值；阶跃子叶 n 不变，d′ = 2d − n·(o − ½)，w′ = 2w（o 为子叶在父叶中的位置）。
  例外（有损）：某个子叶里阶跃较小一侧不到其体积 2% 时，这个子叶改为常数叶（取平均值）；否则小的一侧对应的值几乎不影响任何射线，求解时会失去约束、数值发散。
- **投影**：每个探测器像素对应一条直线，预测值是衰减系数沿直线的精确积分，按叶子边界分段（一条射线在一个叶子里一段），CUDA 计算。三线性叶沿线段是三次多项式，两点高斯求积精确；阶跃叶沿线段 s = n·(u − ½) − d 是线性的，∫H = L·(softplus(s₁/w) − softplus(s₀/w))/((s₁ − s₀)/w) 有闭式解。
  几何固定时场对存储值是线性的：预测投影 = A·c，c 是全部存储值排成的向量，A 的元素都 ≥ 0。

### 2.2 存储格式（预算按它计，codec/）
按层顺序排列（先根网格按光栅顺序，再逐层列出每个分叉结点的 8 个子格），不存任何指针和坐标，解码时由顺序还原：
每个根格子 1 位（叶子或继续切分）、每个分叉结点一个 8 位掩码（哪些子格继续切分）、每个叶子 2 位类型、值用半精度（fp16）。阶跃叶的几何打包成 32 位：方向用八面体编码（把单位球面摊平到正方形上）2×10 位，d 8 位，w 按对数刻度 4 位（0 表示硬阶跃）。
**每叶字节**：常数 2.25，三线性 16.25，阶跃 8.25；每次切分多 1 字节加 7 个子叶；头 64 字节。旧格式是 5 / 19 / 15 字节加每次切分 64 字节，所以同样 8 MiB 现在能装约两倍的内容。
导出时存储值和几何四舍五入到存储精度，再重新加载评测（若有值超出半精度范围直接报错）。

### 2.3 计算格式（GPU，representation/octree.py）
叶子按类型排成"三线性 | 阶跃 | 常数"，同类型内按 Z 序曲线（三个坐标的二进制位交错）排列，空间上相邻的叶子在内存里也相邻。叶子的类型和值的位置都由序号直接算出（三线性叶 i 的 8 个值在 8i 处，32 字节对齐，两次 128 位读取）；阶跃几何只给阶跃叶存，每叶一条 32 字节记录；树 = 根网格一个 32 位数组 + 每个分叉结点一行 8 个 32 位子项（非负为叶子序号，负数为分叉结点序号）；值直接是物理衰减系数。每叶的缓冲区约 30 字节（旧布局 141 字节）。

## 3 流水线

```
48³ 根网格（三线性叶），所有值 = 训练投影平均值的一半
重复（每一轮）：
  0. 阶跃几何更新（有阶跃叶时）        training/geometry.py
  1. 求解值（树、类型、几何固定）       training/solve.py, regularizer.py
  2. 决策：每个叶子比较 5 个选项         refinement/decision.py
  3. 选择（字节价格）
  4. 执行
直到：没有净收益为正的选项 / 剩余预算不到 1% / 达到最大轮数 → 最后一轮全分辨率严格求解
导出：舍入到存储精度 → 评测 → 写存储文件
```

### 3.0 阶跃几何更新
值固定为上一轮的解，对每个阶跃叶做一步阻尼高斯-牛顿：按射线累加几何（方向、位置、宽度）的导数 D = (c₁ − c₀)·∂I/∂几何，得到梯度 Σ 残差·D 和 5×5 矩阵 Σ D·Dᵀ（经过多个阶跃叶的射线，叶间耦合忽略），解 (G + 0.1·diag G)·δ = −g，每部分限幅；方向归一化（d、w 同比缩放，函数不变），w ≥ 四分之一探测器像素，平面留在叶内，两侧都 ≥ 2% 体积，否则该叶不动。整步使完整目标（投影误差 + β·R）下降才接受，否则步长减半，最多 3 次；下一轮从上次接受的步长开始试。

### 3.1 求解值
求 min over c ≥ 0 的 J(c) = ½‖A·c − y‖² + β·R(c)。
- **保边正则 R**：对所有相邻叶子共享面上的采样点（从较细一侧取 2×2 个点），惩罚两侧取值差 t：|t| ≤ δ 时 t²/2（压平叶子间的小台阶），否则 δ(|t| − δ/2)（真实边缘只线性计价）；β = 2300、δ = 0.02，在检验视角上选出；合并像素时 β 按像素倍数的平方缩小。每个采样点存 24 字节，基函数权重分块现算。
- **迭代**：误差 r = A·c − y；梯度 g = Aᵀ·r + β·∇R；每个值的步长分母 d = Aᵀ·A·1 + β·（R 的曲率上界），保证每步不让目标变大；更新 c ← max(0, c − g/d)。
- **加速**：先把 240 个视角按角度交错分成 24 组、每组更新一次（分组阶段正则梯度每遍只算一次）；之后用全部数据更新，并沿上一步方向外推（外推点截断到 ≥ 0），方向变差就取消。
- **粗树用粗数据**：最细叶子在探测器上还跨 ≥ 2.5 个合并像素时，把 2×2 或 4×4 个像素取平均当一条射线求解。
- **收敛判断**：最优性残差 |c − max(0, c − g(c)/d)| / |c| ≤ 容差（每轮 1e-3，最后一轮 1e-4），在返回的值 c 上检查：外推点上的步长变小时，在新的 c 上多取一次梯度来判断，不通过就从 c 继续（动量重置）。
- **未收敛时**继续解同一棵树（复用 d、动量和正则采样点，不再热身），直到收敛，不改结构；整个运行有时间上限（`training.max_seconds`），到时保存模型，状态记为 `time_limit_not_converged`，不称为完成。每轮分别报告：值是否收敛、续解次数、几何更新是否被接受。

### 3.2 决策
- **选项**：保持 / 换成常数 / 换成三线性 / 换成阶跃 / 切分成 8 个同类子叶。
- **阶跃的候选几何**取自当前重建：n = 叶内（含四分之一叶宽邻域）灰度梯度二阶矩的主方向，d = 沿 n 按梯度大小加权的中心（限制在叶子范围的 80% 以内），w = 半个探测器像素；较小一侧不到叶子体积 2% 的候选不允许。
- **射线**：全部 240 个训练视角的全部像素，按角度相邻的视角交替分成两半。
- **局部重新拟合**：其余叶子固定（相同背景），对每个选项做最小二乘，并满足与求解相同的约束：换类型的值 ≥ 0；切分时每个子叶加一个常数修正，修正 ≥ −（该子叶当前的最小值）。在一半视角上拟合、另一半上计算误差，再反过来，两次相加（多出来的参数只有在没参与拟合的视角上也更准时才有收益）。
- **目标值与求解相同**：每一半为 Σ(预测 − 数据)² + β·R；R 在该叶附近换成一个二次函数：每个共享面采样点权重 = 面积 × min(1, δ / 当前两侧差)，在当前值处与 R 相等、其余处都不低于 R，所以正则部分的收益不会被高估；切分时 8 个子叶之间新出现的内部面也计入。
- **收益定义**：
  - 换类型：收益 = J(自己类型，值重新拟合) − J(新类型，重新拟合)，J 是留出一半射线上的残差能量。换类型整体替换叶内函数，所以基线是旧类型的重新拟合，“把值继续优化”的收益不算给换类型；阶跃叶的基线用它当前的几何，候选用新估计的几何。
  - 切分：收益 = J(当前函数) − J(当前函数 + 每个子叶一个常数修正)。修正加在当前函数上，这个函数族里没有父叶的重新拟合，所以不扣重拟合基线（依据见 4.3）。
  - 小于统计精度的收益记为 0（残差能量的 1e-6 加 b² 的 1e-7，b 是“数据减去其余叶子”，内核权重是 float32）。
- **统计量**在 CUDA 遍历中累加到每个叶子，每个（叶子，射线段）102 个数（5 个选项的法方程、b² 和残差²）：每个视角用 float32 累加，视角之间在 double 里相加（收益是比自身大得多的量的差，float32 跨视角求和会把它丢掉）；拟合和收益按叶子分块在 double 里算。
- **限制**：三线性叶和阶跃叶不降级成常数叶（降级丢掉的细节在留出投影里几乎看不出，在体积里看得出）；上一轮刚换过类型的叶子这一轮只能保持或切分；子叶在探测器上必须至少跨 1 个像素。

### 3.3 选择与执行
- **选择**：每个叶子取“收益 − λ × 多用的字节”最大且为正的选项；λ ≥ 0 取使这一轮的净增字节不超过剩余预算 70% 的最小值（省字节的选项在损失小于 λ × 省下字节时也会被采用）；选中的全部执行。
- **执行**：换类型时，用新类型中与该叶子当前函数最接近的函数初始化（叶内 4³ 个采样点上的最小二乘，值 ≥ 0），使模型保持在已求解状态附近；切分保持函数不变；下一轮求解从这里继续。

## 4 设计决定及其实验依据
以下都是 8 MiB 下的体积 PSNR（对真值，越高越好），除非另注。

### 4.1 决策视角数（旧存储格式，提交 73f4954 → f474847）
决策用多少个视角，决定能不能看到切分收益：在 73f4954 的最终模型上，第 0 层边缘叶切分收益 > 0 的比例，16 个视角 17%，64 个 50%，240 个 97%。体积 PSNR 35.06 → 36.31 dB。所以决策用全部 240 个。

### 4.2 保边正则
在 f474847 的树上从同一起点严格求解，β = 0 / 23 / 231 / 2311 / 7704 时检验视角投影 PSNR 51.124 / 51.124 / 51.151 / **51.280** / 50.908，体积 36.312 / 36.312 / 36.324 / 36.413 / 36.302；按检验视角选 β = 2311（配置里取 2300）。完整流程 aee48e1：36.41 dB。决策也计入正则（e9f0f68）在 24 MiB 下没有额外收益（36.93 对 36.98 dB，在噪声内）。

### 4.3 收益定义的对照（同一份代码，只换定义，8 MiB）
| 收益定义 | 体积 PSNR | 第 3 层叶子 |
|---|---|---|
| 旧：当前残差 − 选项 | 37.33 dB | 6.1 万 |
| 所有选项都扣旧类型重拟合 | 35.57 dB | 6.4 万 |
| **类型替换扣基线，切分按当前残差（现行）** | **37.38 dB** | 21.7 万 |

按计划所有选项都扣基线时质量掉 1.8 dB：切分选项的函数族（当前函数 + 修正）不含父叶的重新拟合，却拿去和重拟合后的旧类型比，不公平，深层切分被压掉。严格的做法是父叶值和子叶修正联合拟合（需要父叶基函数与子叶长度的交叉项），未做。统计量改双精度对结果没有影响（旧定义下 37.334 对 37.333 dB）。

### 4.4 阶跃几何更新（容量测试和接入）
在 24 MiB 的树上用真值拟合（只作诊断）：保持几何只重拟合两个值，体积 36.93 → 37.01 dB，阶跃叶上的误差 −4.9%；方向、位置、宽度一起优化，37.40 dB，阶跃叶误差 −19.9%，表面带均方误差 −11%。这是上限（含对真值噪声的拟合）。接入后（只用投影，每轮一步，提交 32aba67，8 MiB）：37.16 → 37.33 dB，测试视角投影 51.81 → 52.70 dB，切面上左上的细裂缝出现，每轮都被接受（前几轮整步，之后半步或四分之一步）。
**薄片叶**（两平行平面之间一个值，两侧另一个值，17 字节）：在 A 之上再测，体积只多 0.06 dB、多用 1.5 MB，主要在拟合真值里的噪声（平坦区出现细针状笔画），放弃。细缝消失的原因不是缺一种叶子类型，而是需要切到第 3、4 层，这是字节分配问题。

### 4.5 掠射角遍历错误（提交 32aba67 修复）
射线和坐标轴夹角很小时（如 0.47°），沿射线轻推 1e-5 的探测点在 float32 下移动不了慢方向的坐标，跨过格子边界后线段被算进前一个格子，单条射线积分最多错 0.49；训练也受影响，测试视角投影 PSNR 因此一直比检验视角低约 2.4 dB。改成沿刚穿过的面推探测点后，全部 260 个视角上 CUDA 与参考实现最大差 1.8e-6，并有回归测试（去掉修复后 5 个 CUDA 测试全部失败）。修复前的所有结果（含 0aa4c1b）都带这个错误。

### 4.6 “扫描圆外”不能置零
旋转轴是模型第 2 轴，真正的扫描圆在第 0、1 轴平面内，圆外有物体（真值均值 0.035）。之前统计的“圆外占 13–24% 字节”其实是第 1、2 轴半径 > 1 的 DICOM 视野外（真值为零），那是参考体的性质，只用投影时不能当约束。

### 4.7 内核优化中放弃的项（都有实测）
每视角新建梯度数组（0.03 毫秒）；解析计算 A·1（每次求解只省一遍）；反投影按类型选择累加方式（慢 40%）、单线程组直接累加（慢 10%）、线程块 64 或 256（更慢）。

## 5 结果

含边缘仍是第 0 层的叶子从 4,217 个降到 363 个。纹理区占体积误差一半以上。

## 6 耗时

### 6.1 规模
一遍数据：240 视角 × 1024² = 2.5 亿条射线；8 MiB 的树上每条射线平均穿过 90 个叶子（中位 83，最多 261），其中阶跃叶占 86%，所以一遍有 228 亿次叶内积分。正投影 0.84 秒（每视角 3.5 毫秒，约每秒 270 亿段）；反投影内核每视角 5.4 毫秒；含射线准备、损失、正则的一遍完整梯度约 2.9 秒。

### 6.2 一次运行花在哪里（94a53a6，循环 660 秒，另有评测导出约 60 秒）
| 部分 | 秒 | 占比 | 原因 |
|---|---|---|---|
| 最后的严格求解 | 266 | 40% | 65 遍；对角步长的一阶法，边缘等高频成分曲率小、收敛慢 |
| 决策（7 次） | 206 | 31% | 每个（叶子，射线段）累加 102 个统计量，是正投影的 14–30 倍；射线统计 141、拟合 48 |
| 每轮解值（8 轮） | 151 | 23% | 每轮约 5 遍 |
| 阶跃几何更新 | 35 | 5% | 每轮一步 |

### 6.3 已做的加速
- 8 MiB 全程 18.4 → 11.9 分钟（32aba67 → 2b4dbe9），结果不变：决策和几何统计的同叶线程分列求和（共享内存，每列只做一次原子加法）、射线按列排列（一个线程束的 32 条射线在旋转平面里同路）、几何更新从上次步长开始、分组阶段正则梯度每遍一次。决策统计 82 → 28 秒/轮，几何统计 14 → 5 秒。
- 反投影同样分列求和（db99906）：每视角完整梯度遍 15.1 → 10.1 毫秒；同状态最后求解 260 → 187 秒（−28%）；被停掉的完整运行里第 3–6 轮解值 −32% 到 −36%；完整运行的全程时间尚未补测。
- 计时波动（同状态重复）：最后求解两次差约 3–8 秒；决策 40–45 秒（拟合一项 7–12 秒波动最大）。

## 7 求解器对比（固定树，尚未接入主线）
从 `states/pre_final_solve.pt` 出发，同一个目标 J、同一个投影器、正则和非负约束，统一用固定分母的参考残差 ρ_ref(c) = |c − max(0, c − ∇J(c)/D_ref)| / |c|（D_ref 为起点处的 D_L + D_R）在返回的值上判断；耗时只计算法本身。对比的是松弛 OS-LALM（Nien & Fessler 2016，arXiv:1512.04564 算法 1）：D_L = diag(Aᵀ·A·1)，D_R = β·正则曲率上界，α = 1.999，ρ 按子迭代递减。

| 方法 | 到 ρ_ref ≤ 1e-4 | 目标值 |
|---|---|---|
| 基线（现行求解器） | 62 遍，182 秒 | 241.516 |
| **12 个子集，论文设置（ρ 按子迭代递减，正则梯度每子迭代重算）** | **6 轮，26.9 秒** | 6 轮 236.99，30 轮 235.98 |
| 12 个子集，正则梯度每轮只算一次 | 发散 | 7169 |
| 24 个子集，论文设置 | 第 4–20 轮目标值冲到 8.9 万（纹波），未达到 | 242.56（30 轮） |
| 24 个子集，ρ 按轮次递减、正则梯度每轮一次（第一版实现） | 发散 | 14.7 万 |

体积评测（同一状态、同一棵树，量化到存储精度）：基线 37.380 dB、表面带 0.016747、远离表面 0.010755、检验视角投影 53.47 dB；松弛 OS-LALM 第 6 轮（26 秒）37.428 / 0.016639 / 0.010713 / 53.65，第 12、20、30 轮几乎不变（37.43 dB）。各轮切面（`output/_chain/lalm_epochs_vs_baseline.png`）看不出区别，与基线的差别集中在中部暗缝和左上裂缝的细节处，没有新的块状伪影。
结论：最后求解快约 7 倍，体积 +0.05 dB，表面带误差 −0.7%，满足接入门槛（至少快 25%、体积下降 ≤ 0.02 dB、表面带误差增加 ≤ 0.5%）；基线停在离最小值较远处，说明参考残差判据偏松。

## 8 已知缺口与下一步
**已知缺口**
1. 最后的严格求解（40%）和决策（31%）是时间大头；参考残差判据偏松（基线 ρ_ref ≤ 1e-4 时目标值仍高 2.3%），“值收敛”的含义要重新界定。
2. 切分收益不含父叶值的重新拟合；联合拟合需要交叉项，未做。
3. 阶跃切分的 2% 规则有损：每轮约 4–5 成的阶跃子叶被转成常数，函数最大变化 0.12–0.5，均方根 0.001–0.004。
4. 阶跃几何每轮只做一步高斯-牛顿，梯度不含正则对几何的导数（接受与否按完整目标判断）。
5. 字节有价格以后，三线性叶换阶跃叶（省 8 字节）仍被大量采用，平坦区域出现块状；细缝需要切到第 3、4 层，决策一步看不远（视野效应）。
6. 保边正则强度只在一棵树上选过；决策统计的双精度累加多占约 1.5 GB 显存。

**下一步（按建议顺序）**
1. 把松弛 OS-LALM 接成最后求解：子集数只用目标值和参考残差选（不看真值），轮数取目标值曲线的拐点（预计约 6 轮）；再决定是否用于每轮解值；按规矩删旧求解器，用新提交完整跑一遍 8 MiB，补测 db99906 之后的全流程时间。
2. 决策加速：拟合部分改闭式解和提前退出（常数闭式、两值阶跃枚举、八值无约束解满足下界就结束）、候选预筛选；目标是决策耗时降 20% 以上。
3. 对细缝：先做离线测试（用真值比较“切一层”和“切两层”的收益），再决定是否做两层前瞻或先长后剪。
4. 按探测器方向的频率加权度量（让求解和决策优化的量等于体积误差，同时改善收敛）：先离线比较两种度量下的决策收益与真值体积收益的一致性。
5. 若松弛 OS-LALM 仍不够：比较带滤波预条件的原始—对偶法（2025 年 JMIV，只查了摘要，未读全文）。
